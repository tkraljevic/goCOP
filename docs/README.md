# Dokumentacija goCOP-a

Kako se program koristi, piše u samom programu, na stranici **Pomoć**.
Ovdje je ono što o programu treba znati izvan njega: kako radi, kako se
instalira, što dolazi i kakav je kod.

## O aplikaciji

- [Kako goCOP radi](kako-radi.md): svako računalo ima svoje podatke; kako
  se računala usklađuju i što radi bez interneta.
- [Tko što radi u programu](uloge.md): uloge, dužnosti i što koja smije.
- [Stadiji obrane](stadiji-obrane.md): kako program iz ovjerenih akata
  računa stanje obrane.
- Podaci i metode: [rekonstrukcija nizova vodostaja](rekonstrukcija-nizova.md),
  [kote nule i baltičke kote](balticke-kote.md),
  [riječni kilometri prema ENC kartama](stacionaza-enc.md).

## Instalacija

- [Prvo pokretanje](prvo-pokretanje.md): za početak, u nekoliko koraka.
- [Upute administratoru](INSTALACIJA.md): postavljanje, mreža, sigurnosna
  kopija, nadogradnja.
- [goCOP na Linuxu](linux.md): stalno računalo kao usluga sustava.
- [Postava](postava.md): instalacijski program i što još dolazi.
- [Predlošci uvoza](predlosci/README.md): oblik datoteka za registre i prvo
  punjenje, s izmišljenim primjerima.
- [Karte](karta.md): podloge karte i kako ih promijeniti, karta bez
  interneta i crtanje objekata i tokova na karti.
- [Pravila potpisivanja](CODE_SIGNING.md), na engleskom: potpis programa za
  Windows i što program šalje izvan računala.

## Plan razvoja

- [Plan razvoja](plan-razvoja.md): što dolazi, kojim redom i zašto.
- [Odluke](odluke.md): odluke o radu programa, po datumu. Na njih se poziva
  i kod.

## Kvaliteta koda

- [Kvaliteta koda](CODE_QUALITY.md): cilj, sadašnje stanje, pravila pisanja
  koda i kako se provjerava.
